# 店赢OS 会员管理

## When to Run

- "看看会员情况" / "最近会员活跃度怎么样"
- "哪些会员快流失了" / "会员流失预警"
- "给高价值会员发优惠券" / "会员复购分析"

## Workflow

1. 拉取会员数据（活跃度/消费频次/客单价/最后消费时间）
2. AI识别高价值会员和流失风险会员
3. 生成分层营销策略（新人礼/复购券/唤醒优惠）
4. 自动推送个性化优惠信息

## Output Format

会员分层 → 流失预警名单 → 精准营销方案 → 预期效果
