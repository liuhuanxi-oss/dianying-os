# 店赢OS 支付投诉处理

## When to Run

- "处理支付投诉" / "看看有没有新投诉"
- "这个投诉该不该退款" / "帮我退款"
- "投诉风险分析" / "风险商户检测"

## Workflow

1. 拉取微信支付V3 / 支付宝投诉列表
2. AI分析投诉类型（商品/服务/欺诈/重复扣款）
3. 紧急度评分 + 退款建议（全额/部分/拒绝）
4. 执行退款（调用随行付/天阙接口）
5. 同步处理结果到微信/支付宝平台
6. 自动检测风险商户（30天投诉≥3条）

## Output Format

投诉汇总 → AI分诊建议 → 退款执行 → 平台同步确认
