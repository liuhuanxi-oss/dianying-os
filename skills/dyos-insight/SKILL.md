# 店赢OS 经营洞察

## When to Run

- "本周经营怎么样" / "这个月赚了多少"
- "分析一下营收下降原因" / "对比上周情况"
- "生成经营报告" / "给我看数据大屏"

## Workflow

1. 汇总GMV、订单量、客单价、好评率等核心指标
2. AI对比历史趋势，识别异常点
3. 诊断根因（差评增加？天气？竞品活动？）
4. 给出可执行的改进建议
5. 生成可视化报告

## Output Format

📊 数据概览 → 📈 趋势对比 → 🔍 异常诊断 → 💡 改进建议
