# 店赢OS 评价管理

## When to Run

当用户需要以下操作时触发：
- "帮我处理差评" / "看看今天的评价" / "回复美团差评"
- "生成这条评价的回复" / "批量AI回复"
- "分析最近评价情况" / "评价关键词分析"
- "菜品好评排行" / "看看顾客都在说什么"

当用户说以下内容时**不要触发**：
- 支付投诉 / 退款 (→ dyos-complaint)
- 定价调整 / 优惠券 (→ dyos-pricing)
- 经营报表 (→ dyos-insight)

## Workflow

### 1. 拉取评价
调用店赢OS本地API获取待处理评价：
```
GET http://localhost:8081/api/admin/reviews?status=PENDING&page=1&size=10
Authorization: Bearer <token>
```

### 2. AI分析
对每条评价执行：
- **情感分析**：正面/中性/负面
- **意图识别**：菜品问题/服务态度/配送问题/价格意见/环境卫生
- **紧急度评分**：1-5分，3分以上建议优先处理
- **回复建议**：根据评价内容和商户风格生成个性化回复

### 3. 生成回复
回复生成规则：
- 带顾客称呼（从用户名提取）
- 针对具体问题回应（不要模板化）
- 给出补偿方案（折扣/赠品/下次优惠）
- 品牌前缀 + 引导复购结尾（可配置）
- 回复长度控制在80-200字

### 4. 同步平台
```
POST http://localhost:8081/api/admin/reviews/{id}/reply
Body: { "ai_reply": "回复内容", "sync": true }
```

同步后自动标记评价状态为"已回复"。

## 多平台适配

| 平台 | 回复字数限制 | 特殊规则 |
|------|-------------|---------|
| 美团 | 500字 | 不可含微信号/手机号 |
| 饿了么 | 200字 | 不可含外链 |
| 大众点评 | 500字 | 可带话题标签 |
| 抖音 | 100字 | 纯文本无格式 |
| 小红书 | 300字 | 可带emoji |

## 配置项

可在店赢OS管理后台 `http://localhost:8081` → 评价管理 → 回复规则中配置：
- 品牌前缀模板
- 回复语气（亲切/专业/活泼）
- 结尾引导语
- 自动同步开关
