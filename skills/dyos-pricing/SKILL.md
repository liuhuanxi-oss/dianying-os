# 店赢OS 智能定价

## When to Run

- "分析最近定价合不合理" / "帮我看看要不要调价"
- "雨天套餐怎么定价" / "周末火锅套餐建议"
- "竞品价格对比" / "毛利分析"

## Workflow

1. 拉取门店菜品销售数据和毛利
2. 查询竞品平台价格（美团/饿了么同类商品）
3. 结合天气、节假日、时段因素
4. AI生成调价建议（涨幅/降幅/套餐组合）
5. 商家确认后自动同步到外卖平台

## Output Format

展示当前价格 → 竞品对比 → AI建议 → 预期增收 → 一键执行
